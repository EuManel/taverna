# Changelog

**English** · [Português](#português)

All notable changes to Taverna. Versions follow `MAJOR.MINOR.PATCH`; the GitHub Release tag is `vMAJOR.MINOR`
(or `vMAJOR.MINOR.PATCH` for fixes). Downloads: <https://omanel.itch.io/taverna> ·
[GitHub Releases](https://github.com/EuManel/taverna/releases).

## [1.0.1] — unreleased

### Added
- The start screen shows a small notice when a newer version is out (it checks the latest GitHub Release at
  most once a day; the link opens itch.io — nothing is downloaded automatically, and it works normally offline).
- Changelog, issue templates (bug report and idea) and a release guide (`COMO_LANCAR_VERSAO.md`).

## [1.0] — 2026-11-20

First public release.

### Added
- One program for everyone: the **Game Master** hosts the table, **Players** join with a room code (automatic
  UPnP) or through Radmin VPN.
- 3D table with a camera that rotates and tilts; walls, doors, objects and tokens with height; floors.
- Building tools, vision cones, fog of war, dynamic lights with shadows.
- Combat with initiative, turns, speed limits and conditions; 3D dice; chat with whispers.
- Atmosphere: weather, areas of effect that react to each other, gas and liquids, sound board and YouTube
  music (official player).
- Chests and loot tables, traps and triggers, documents, projector, world and city maps, campaign journal.
- PDF library, fillable PDF sheets for any system, D&D 5e sheet with the SRD 5.1, token library, image bank
  with an AI background remover.
- 9 visual themes and Low / Medium / High graphics.
- **English and Portuguese**, chosen with the flags on the start screen.
- Windows build: a folder with `Taverna.exe` (no install, no Python), `README.txt` and `HOW_TO_CONNECT.txt`.
- License: GPL-3.0.

## [1.0] — 20/11/2026

Primeira versão pública.

### Novo
- Um programa só pra todo mundo: o **Mestre** abre a mesa e os **Jogadores** entram com o código da sala (UPnP
  automático) ou pelo Radmin VPN.
- Mesa em 3D com câmera que gira e inclina; paredes, portas, objetos e fichas com altura; andares.
- Ferramentas de construção, cone de visão, névoa de guerra, luzes dinâmicas com sombra.
- Combate com iniciativa, turnos, limite de deslocamento e condições; dados 3D; chat com sussurro.
- Atmosfera: clima, áreas de efeito que reagem entre si, gás e líquidos, mesa de sons e música do YouTube
  (player oficial).
- Baús e tabelas de loot, armadilhas e gatilhos, documentos, projetor, mapas de mundo e cidade, diário.
- Biblioteca de PDFs, fichas em PDF preenchível de qualquer sistema, ficha de D&D 5e com o SRD 5.1, biblioteca
  de tokens, banco de imagens com removedor de fundo com IA.
- 9 temas visuais e gráficos Baixo / Médio / Alto.
- **Inglês e português**, escolhidos pelas bandeirinhas da tela inicial.
- Versão pra Windows: uma pasta com o `Taverna.exe` (sem instalar, sem Python), `README.txt` e
  `HOW_TO_CONNECT.txt`.
- Licença: GPL-3.0.
