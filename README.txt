==========================================================
  TAVERNA {VERSAO} — online tabletop RPG (Windows)
==========================================================

[ ENGLISH ]   (Português mais abaixo)

OPENING
1. Unzip to a folder (don't run it from inside the zip).
2. Run "Taverna.exe". No install, no Python needed.
3. If Windows says "Windows protected your PC":
   More info -> Run anyway (the .exe isn't code-signed).
4. Language: the little flags at the bottom of the start screen.

GAME MASTER (hosts the table)
1. Start screen -> Game Master -> New session.
2. "Open tavern" button (top right) -> Open.
   First time: in the Firewall prompt tick Private AND Public.
3. If it shows "Open over the internet · TAV-XXXXX-XXXXX",
   click it, copy the code and send it to your players.
   If it can't open over the internet: use Radmin VPN (below).

PLAYERS
1. Start screen -> Player -> Join session.
2. Your name + the TAV-... code (or the GM's IP) + port 7777.

CAN'T CONNECT OVER THE INTERNET? Radmin VPN (free, radmin-vpn.com)
- Everyone installs it. The GM creates a network (name + password),
  players join it and use the GM's IP starting with 26. instead
  of the code.
- Same house / same Wi-Fi: use the GM's local IP (192.168...).

==========================================================
  TAVERNA {VERSAO} — mesa de RPG online (Windows)
==========================================================

[ PORTUGUÊS ]

ABRIR
1. Descompacte o .zip numa pasta (não rode de dentro do zip).
2. Abra "Taverna.exe". Não precisa instalar nem ter Python.
3. Se o Windows disser "O Windows protegeu o computador":
   Mais informações -> Executar assim mesmo
   (o .exe não tem assinatura paga, é normal).
4. Idioma: as bandeirinhas no canto de baixo da tela inicial.

MESTRE (quem abre a mesa)
1. Tela inicial -> Mestre -> Nova sessão.
2. Botão "Abrir taverna" (canto de cima, à direita) -> Abrir.
   Primeira vez: no aviso do Firewall marque Privada E Pública.
3. Se aparecer "Aberta pela internet · TAV-XXXXX-XXXXX",
   clique, copie o código e mande pros jogadores.
   Se não abrir pela internet: use o Radmin VPN (abaixo).

JOGADORES
1. Tela inicial -> Jogador -> Entrar na sessão.
2. Seu nome + o código TAV-... (ou o IP do mestre) + porta 7777.

NÃO ABRIU PELA INTERNET? Radmin VPN (grátis, radmin-vpn.com)
- Todo mundo instala. O mestre cria uma rede (nome + senha),
  os jogadores entram nela, e usam o IP do mestre que começa
  com 26. no lugar do código.
- Mesma casa / mesmo Wi-Fi: use o IP local do mestre (192.168...).
