# Teste com os amigos — roteiro do Manel

Já conferido antes (sozinho, no teu PC): 5 jogadores ao mesmo tempo pela rede local, todo mundo vê os movimentos de
todo mundo, ninguém mexe no token dos outros, a mesa vai comprimida (upload do mestre ~0,5 Mbps arrastando token).
O que falta só dá pra ver com gente de verdade, em outra casa.

## Antes (5 min)

1. Gere o release (`gerar_exe.bat`) e mande o zip da pasta `release` (o `Taverna.exe` + `README.txt` + `HOW_TO_CONNECT.txt`).
2. Na tua rede o UPnP **não abriu** a porta → use o **Radmin VPN**: crie a rede e mande nome + senha.
3. Amigo com Windows "protegeu o computador": *Mais informações → Executar assim mesmo*.

## Durante (marque o que deu certo)

**Conexão**
- [ ] Todo mundo entrou (Jogador → Entrar na sessão → IP 26.x do mestre).
- [ ] Alguém caiu e voltou sozinho? (fechar o Radmin de um e abrir de novo)
- [ ] O token de cada um: vincular (Editar token → Jogador) e cada um move só o seu.

**Mesa**
- [ ] Mapa e tokens aparecem pra todos; imagem pesada demora quanto pra chegar?
- [ ] Névoa e visão: cada um vê só o que o token dele vê.
- [ ] Porta: abrir/fechar aparece pra todos.
- [ ] Câmera livre (Alt+arrastar / bússola) e "Ver pelos olhos" na máquina de cada um.
- [ ] Standee e ficha; status com partículas (pôr "queimando" em alguém).

**Jogo**
- [ ] Rolagens: cada um rola, todo mundo vê os dados 3D (com a cara dos dados de cada um).
- [ ] Combate: iniciativa, a vez passa, "encerrar turno" do jogador.
- [ ] Chat e sussurro; diário.
- [ ] Ficha (PDF importado) abre e salva.
- [ ] Música do YouTube e mesa de sons: todos ouvem? **(nunca conferido no .exe)**
- [ ] Efeitos: explosão, área de fogo, clima.

**Desempenho** (pergunte a cada um)
- [ ] Placa de vídeo / PC de cada um, e se ficou travando (em qual nível de Gráficos).
- [ ] Atraso pra ver o movimento dos outros (fala "agora" quando mexer).

## Se der problema

Quem viu o problema: **Ajuda → 🐞 Reportar problema…** → descreve → gera um `.zip` → manda pro Manel.
(Leva o `erros.log` e o sistema; a aventura só vai se marcar.) Me passa os `.zip` e o que vocês anotaram aqui.
